Frequently asked questions

Clear answers about the reference pack.

What Site Stripper observes, what it includes, and where the boundaries are.

Does Site Stripper use an AI model to analyze a website?

No. Site Stripper collects structured observations. The resulting pack can support a separate AI-assisted rebuild workflow.

Which websites can I analyze?

Public HTTP or HTTPS websites. Site Stripper follows relevant same-site pages selected from the site structure.

How many pages can a run include?

Hosted runs can analyze up to 10 pages and run for up to 150 seconds.

Will every pack contain screenshots?

Screenshot files are included when captures succeed and fit the hosted limits. Results can be partial or have no capture files.

Does Site Stripper make an offline copy of the original website?

No. It creates a structured reference pack. It does not submit source-site forms, bypass bot checks, or replay arbitrary JavaScript interactions.

What is inside the ZIP?

Markdown guides, JSON records, theme files, page notes, and capture files when available. The sample pack shows representative paths.
