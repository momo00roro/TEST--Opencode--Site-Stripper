Product features

Visual DNA for your next build.

Site Stripper turns page structure, visible content, design tokens, layout, responsive behavior, imagery, and available captures into a comprehensive reference ZIP. Use it to start a new site in the reference's style with Claude Code, Codex, OpenCode, Cursor, and any other AI agent that supports MCP or can read project files.

Page discovery

Find likely key pages from public navigation, site-map entries, and relevant same-site links. The selection report preserves the candidates and explains which pages made it into a bounded run.

Structured observations

Keep headings, sections, visible copy, layout samples, control labels, media references, and design tokens connected to their source page.

Available captures

Review desktop, mobile, and section captures when they are available. Slow or protected pages and hosted limits can make capture coverage partial.

Machine-readable records

Use page, token, navigation, interaction, asset, selection, responsive, and report data alongside the written guides.

Rebuild documentation

Carry page notes, information architecture, responsive observations, typography, imagery, content style, and implementation guidance forward.

Portable ZIP delivery

The browser validates the generated documents and structured files, then assembles a portable ZIP with capture binaries when available.

A build brief for AI agents

Give a new website the same visual DNA.

The comprehensive ZIP brings page structure, visible content, design tokens, typography, layout data, responsive notes, art direction, and source assets and captures when available into one usable brief. It helps Claude Code, Codex, OpenCode, Cursor, and any other AI agent that can read project files quickly understand the reference and start a brand-new site in its visual language.

Local MCP connection

Your agent can request Visual DNA directly.

Run the local Site Stripper workspace, choose an MCP-compatible client, and copy its connection details. Claude Code, Codex, OpenCode, Cursor, and any other AI agent that supports MCP can ask for an analysis and then request focused source evidence as it builds.

Site Stripper does not run a model API. Your selected agent handles model reasoning with its own provider. That provider may process website evidence under its own settings and policies.

Responsive evidence

See how a page adapts to a smaller screen.

Responsive notes help a team compare page structure across viewports. The reference pack can include desktop and mobile captures when available, plus responsive observations that describe what changed.

  • Compare layout shifts and content order.
  • Review observed typography and spacing patterns.
  • Keep capture coverage visible in the report.
How the process works

Package structure

Start with the overview, then open page-level files.

The output separates the page map, individual page notes, reusable design observations, and structured records.

01

Start with the overview

README.md summarizes the source, page coverage, and report status. REBUILD.md gathers implementation guidance in one place.

02

Trace the page set

Information architecture and selection records show how the analyzed pages relate and why candidates were selected or excluded.

03

Inspect design evidence

Token, typography, responsive, imagery, and interaction notes capture details that a screenshot alone cannot explain.

04

Use the structured files

JSON records keep page, asset, navigation, layout, and report details available for tools that prefer structured input.

Run limits

Review coverage and capture status.

Hosted analysis can return partial observations when pages are protected, slow, or media-heavy.

  • Up to 10 pagesMaximum selected pages in one run.
  • 150 secondsHosted analysis wall limit.
  • Captures when availableSource-site behavior and hosted limits affect screenshots.

Site Stripper observes public pages. It does not submit source-site forms, solve CAPTCHA challenges, bypass bot checks, or replay arbitrary JavaScript interactions.
