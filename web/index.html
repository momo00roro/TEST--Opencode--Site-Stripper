WORKS WITH YOUR CODING AGENT

Your coding agent can request the evidence.

This is a coding-agent rebuild workflow. Run the local workspace and connect Claude Code, Codex, OpenCode, Cursor, or any other AI agent that supports MCP. The agent can ask Site Stripper to analyze a public website, inspect its Visual DNA, and request page evidence as it builds a new site in the same style.

Site Stripper does not run a model. Your chosen agent performs the reasoning and implementation with its own provider. When you prefer a manual handoff, the comprehensive ZIP and a copyable prompt are ready as a fallback.

Limits and coverage

Know what each run includes.

How many pages can one run analyze?

Hosted runs can analyze up to 10 selected pages in up to 150 seconds.

Are screenshots included in every pack?

Capture files are included when available. Source-site behavior and hosted limits can make captures partial or unavailable.

Does Site Stripper rebuild the website?

No. It gathers reference material to guide a separate design and development workflow.
