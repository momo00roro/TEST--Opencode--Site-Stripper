Build from the visual DNA

Give a new site the same style and art direction.

The comprehensive ZIP gives a coding agent a strong starting point: page notes, typography, colors, design tokens, layout and responsive records, imagery, and captures when available. It helps Claude Code, Codex, OpenCode, Cursor, and any other AI agent that can read project files quickly understand the reference and build a new site in its visual language.

1 Inspect

Open the ZIP contents

Begin with README.md and REBUILD.md, then review page notes and the selection report.

2 Ground

Use design tokens

Provide data/tokens.json, data/layout.json, responsive records, and available assets to your agent.

3 Build

Match the source style

Ask it to follow the same page structure, palette, typography, imagery, and art direction.

Claude CodeCodexOpenCodeCursorAny other AI agent
4 Review

Compare the result

Check the rebuilt page against available reference captures and responsive notes.

Local MCP connection

Ask your agent for Visual DNA directly.

The local workspace exposes an MCP endpoint while it is running. Connect Claude Code, Codex, OpenCode, Cursor, or any other AI agent that supports MCP, then ask it to analyze a public site and read focused evidence. The agent's provider performs model reasoning from the evidence it receives.

Connect onceChoose your client in Agent connections and copy its setup. The local URL uses the port shown by the workspace.
Request evidenceCall analyze_public_site, get_visual_dna, get_page_evidence, or get_rebuild_brief when the task needs them.
Keep the ZIP nearbyDownload the comprehensive archive and use it as a manual handoff when you prefer files over direct MCP access.

Site Stripper makes no model API call. The agent provider may process page text and design observations under its own settings and policies.
